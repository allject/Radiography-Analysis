# Radiography Analysis

A local/static HTML application for dental radiograph ROI alignment, fractal dimension analysis, densitometry and ImageJ-compatible Excel export.

## Use

Open `radiography-analysis.html`, import radiographs, draw an ROI, align targets to the first reference image, verify with Overlay and calculate. See `user-guide.html?lang=en` for the full manual.
