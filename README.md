Languages

The interface and guide support Turkish, English and German through an extensible dropdown-based language registry in radiography-languages.js. The last selected language is remembered in the browser.

Quick start
Open radiography-analysis.html locally, download the Latest ZIP, or access it via GitHub Pages.
Import one or more radiographs. One image runs analysis mode; two or more images use reference-first comparison mode.
Draw ROI, align, verify with Overlay, calculate, then copy Excel output.
Open user-guide.html for the detailed trilingual manual and Excel column dictionary.
